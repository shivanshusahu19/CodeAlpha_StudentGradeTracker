# CodeAlpha Student Grade Tracker

## 📌 Project Overview

Student Grade Tracker is a Java-based console application developed as part of the CodeAlpha Java Programming Internship.

The application allows users to enter student names and marks and generates a student performance report.

## 🚀 Features

- Add multiple students
- Enter student marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Automatically calculate grades
- Validate marks between 0 and 100
- Display student performance report

## 🛠️ Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## 📚 Concepts Used

- Classes and Objects
- ArrayList
- Loops
- Conditional Statements
- Methods
- User Input
- Basic Data Processing

## ▶️ How to Run

1. Open `StudentGradeTracker.java`
2. Compile and run the Java program
3. Enter the number of students
4. Enter student names and marks
5. View the generated student report

## 📊 Project Output

The program displays:

- Student name
- Marks
- Grade
- Average marks
- Highest marks
- Lowest marks
